# УгадайЧисло Бот

Телеграм-бот для групп: админ стартует раунд угадывания числа (1–100), участники шлют целые числа, бот отвечает «higher», «lower» или «correct — @username wins!» и фиксирует результаты.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
